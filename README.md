# Fulltank+

Website institucional para clientes e donos de postos.

Arquivos estáticos em `dist/`. Abra `dist/index.html` ou execute `python3 -m http.server 8080 --directory dist`.

Antes de publicar, configure os links oficiais Android/iOS e WhatsApp comercial em `dist/config.js`. Sem configuração, o site informa que o canal está pendente e não envia nem armazena os dados do formulário.

Calculadora: simulação ilustrativa de R$0,10 por litro, sujeita às condições reais de cada posto. Telas reais fornecidas pelo cliente, sem dados pessoais. Os valores do dashboard não são promessa de resultado.
